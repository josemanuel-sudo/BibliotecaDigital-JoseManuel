BACKEND

API REST de Biblioteca Digital

La API está desarrollada con ASP.NET Core y .NET 10. Permite gestionar los libros y los préstamos.

Método Endpoint Descripción
GET /api/health Comprobar el estado de la API
GET /api/books Consultar todos los libros
GET /api/books/{id} Consultar un libro
POST /api/books Crear un libro
DELETE /api/books/{id} Eliminar un libro
GET /api/loans Consultar préstamos
GET /api/loans/{id} Consultar un préstamo
POST /api/loans Crear un préstamo
PUT /api/loans/{id}/return Devolver un préstamo
Información importante

Esta web se publica como contenido estático mediante GitHub Pages. La API .NET no está desplegada en este alojamiento y sus endpoints no se pueden ejecutar desde este portal.
